/*
    The American Household -- AH_recipes_food.txt
    ==================================================================
    SECTION A: OVERRIDES of vanilla craftRecipe blocks.
    Every override below is a VERBATIM copy of the corresponding block
    from the Build 42.20 generated scripts (recipes_baking.txt /
    recipes_cooking.txt), with ONLY the noted input lines widened:

      * mixing-vessel lines: [Base.Bowl;Base.ClayBowl] extended to
        [Base.Bowl;Base.ClayBowl;Base.Pot;Base.Saucepan;
         Base.SaucepanCopper;Base.Pan;Base.RoastingPan;Base.BakingPan;
         Base.BucketEmpty]
      * rolling-pin lines: [Base.RollingPin] / tags[base:rollingpin]
        replaced by [Base.RollingPin;Base.Wine;Base.Wine2]
        (a full wine bottle is the classic improvised roller; Wine and
        Wine2 are B42 fluid-container bottles, valid empty or full)

    Nothing else in these blocks is changed. Design rule (design doc
    section 7.3): a recipe should specify a capability, not a SKU --
    substitution degrades but never gates.

    SECTION B: NEW AH_ recipes (additions, zero conflict surface).
    Improvised can opening per design section 7.3: screwdriver + hammer,
    penalized (time = 250 vs the vanilla knife variant's 80). Copied
    from the vanilla can-opening recipes with only the tool inputs and
    time changed.
    NOTE: the design's contents-loss chance is DEFERRED -- it needs a
    custom lua OnCreate; these recipes currently reuse the vanilla
    OnCreate handlers unchanged.

    MAINTENANCE: on any game update, re-diff every block in Section A
    against the new vanilla generated scripts (see OVERRIDES.md).
*/
